직접 조사한 뒤 마음에 드는 물건을 모아 둔 곳입니다. 상태와 메모는 저장소에 기록됩니다.

설정

관심 물건을 GitHub 저장소(docs/data/favorites.json)에 저장하려면 GitHub 토큰이 한 번 필요합니다. 토큰은 이 브라우저에만 보관되고 GitHub 외에는 보내지 않습니다.

  1. GitHub → Fine-grained token 만들기
  2. Repository access: Only select repositories → 이 저장소만 선택
  3. Permissions → Repository permissions → Contents: Read and write
  4. 만든 토큰(github_pat_…)을 아래에 붙여넣기
